สวัสดีค่ะ อาริศาช่วยดูแลสุขภาพให้นะคะ 💚

สิ่งที่คุณทำได้บน MedEase

  • จองคิวนัดหมายแพทย์ เลือกแผนก วันที่ และช่วงเวลา
  • ส่งคำขอใบรับรองแพทย์ และรับไฟล์ PDF ผ่านลิงก์
  • อ่านข่าวสุขภาพที่ถูกต้อง ใช้ภาษาที่เข้าใจง่าย
ข้อมูลทั้งหมดถูกจัดเก็บบน Firebase และเชื่อมต่อผ่าน LINE Messaging API เพื่อความปลอดภัยและใช้งานได้จริงในชีวิตประจำวัน

ฟีเจอร์หลักของ MedEase

ครอบคลุมตั้งแต่การนัดหมาย การขอใบรับรอง การติดตามสุขภาพ ไปจนถึงข่าวสารสุขภาพในที่เดียว

จองนัดหมายแพทย์

เลือกแผนก วัน และช่วงเวลาได้เองผ่าน LINE ไม่ต้องโทรไปโรงพยาบาลและรอคิวนาน

  • แสดงสถานะนัดหมาย (pending / confirmed / cancelled)
  • แพทย์หรือแอดมินจัดการคิวผ่านหน้าเว็บแอดมิน

ขอใบรับรองแพทย์ออนไลน์

ส่งคำขอใบรับรองผ่านแชท จากนั้นแพทย์ตรวจสอบและอัปโหลดไฟล์ PDF ให้ดาวน์โหลดได้

  • จัดเก็บคำขอใน Firestore
  • รองรับการส่งลิงก์ดาวน์โหลดผ่าน LINE หรืออีเมล

ข่าวสุขภาพจากแหล่งที่เชื่อถือได้

หน้า MedEase Health News แสดงข่าวจากฐานข้อมูล Firestore พร้อมระบบจัดการข่าวสำหรับแอดมิน

  • ข่าวแยกเป็นหัวข้อและหมวดหมู่
  • หน้าอ่านข่าวเต็มรองรับภาพ วิดีโอ และไฟล์เอกสาร

แชทบอท “อาริศา”

ผู้ช่วยอัจฉริยะที่คอยตอบคำถาม นำทางผู้ใช้ไปยังเมนูต่าง ๆ และเชื่อมต่อกับระบบนัดหมาย / ใบรับรอง / ข่าวสุขภาพ

  • ใช้ LINE Messaging API + Node.js / Express
  • รองรับการพัฒนาเพิ่มเติมด้วย AI / Infermedica

Cloud & Security

ออกแบบบน Firebase และ Cloud ทำให้รองรับการขยายตัว ปลอดภัย และดูแลง่ายสำหรับทีมพัฒนา

  • ใช้ Firestore / Auth / Hosting ของ Firebase
  • รองรับการยืนยันตัวตนและการแบ่งสิทธิ์แอดมิน

MedEase ทำงานอย่างไร?

ขั้นตอนที่ 1

เพิ่มเพื่อน & เริ่มแชท

ผู้ใช้เพิ่ม MedEase เป็นเพื่อนใน LINE จากนั้นพิมพ์ทัก “สวัสดี” หรือเลือกเมนูจากริชเมนูเพื่อเริ่มใช้งาน

ขั้นตอนที่ 2

แชทกับอาริศา เลือกบริการที่ต้องการ

แชทบอทอาริศานำทางไปยังฟังก์ชัน เช่น นัดหมายแพทย์ ขอใบรับรอง ดูข่าวสุขภาพ หรือเปิดหน้าเว็บ LIFF ให้กรอกข้อมูล

ขั้นตอนที่ 3

เบื้องหลังด้วย Cloud & Dashboard แอดมิน

ข้อมูลทั้งหมดถูกเก็บใน Firestore แอดมินจัดการคิว ใบรับรอง และข่าวผ่านหน้าเว็บ MedEase Admin ได้อย่างเป็นระบบ

ประโยชน์สำหรับโรงพยาบาล / คลินิก

MedEase ถูกออกแบบให้เป็น “ต้นแบบระบบสุขภาพบน LINE” ที่สามารถนำไปต่อยอดใช้จริงในองค์กรด้านสาธารณสุขได้

  • ลดภาระเจ้าหน้าที่ในการรับสายและจองคิวนัดหมาย
  • จัดการคิวผู้ป่วยและคำขอใบรับรองได้จากหน้าเว็บแอดมินเดียว
  • เก็บข้อมูลผู้ป่วยและประวัติสุขภาพอย่างเป็นระบบ นำไปใช้วิเคราะห์ต่อได้
  • เพิ่มช่องทางสื่อสารข่าวสารสุขภาพให้ประชาชนเข้าถึงง่ายผ่าน LINE

เทคโนโลยีที่ใช้พัฒนา

  • LINE Messaging API / LINE LIFF
  • Node.js + Express สำหรับ Webhook และ Backend
  • Firebase Authentication, Firestore, Hosting
  • HTML, CSS, TailwindCSS สำหรับส่วน UI
  • GitHub + VS Code สำหรับจัดการซอร์สโค้ด

โครงสร้างระบบวางบน Cloud ทำให้รองรับการขยายจำนวนผู้ใช้ในอนาคตได้ดี และสะดวกต่อการดูแลรักษา

MedEase ในมุมมองโครงงานวิชาการ

ที่มาและวัตถุประสงค์

พัฒนาขึ้นเพื่อลดปัญหาการติดต่อโรงพยาบาลล่าช้า การจองคิวที่ยุ่งยาก และการขาดระบบติดตามประวัติสุขภาพของผู้ใช้ในปัจจุบัน

  • ให้ผู้ใช้จองนัดหมายแพทย์ได้ด้วยตนเองผ่าน LINE
  • ขอใบรับรองแพทย์แบบออนไลน์
  • มีระบบจัดเก็บประวัติสุขภาพส่วนบุคคลแบบดิจิทัล
  • เผยแพร่ข่าวสารและความรู้ด้านสุขภาพที่ถูกต้อง

คุณค่าที่คาดว่าจะได้รับ

  • ผู้ใช้ลดเวลาเดินทางและรอคิว สามารถจัดการสุขภาพของตนเองได้ดีขึ้น
  • โรงพยาบาลบริหารจัดการคิวนัดหมายได้อย่างมีประสิทธิภาพ
  • เป็นตัวอย่างการประยุกต์ใช้ Chatbot และ Cloud ในงานสาธารณสุข
  • ผู้พัฒนามีทักษะการสร้าง Web Application และระบบบน Cloud ที่ต่อยอดได้จริง
